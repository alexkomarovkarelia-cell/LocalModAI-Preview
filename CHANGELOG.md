# История выпусков

## v0.5.0-alpha.1

Первая публичная тестовая сборка LocalModAI для Windows.

### Добавлено

- создание и открытие проектов;
- несколько связанных чатов внутри проекта;
- базовая Project Memory — память проекта;
- подключение локальных GGUF-моделей;
- краткое понимание проекта перед планированием;
- Planning Intake — сбор подробного контекста;
- создание Plan Candidate — черновика плана;
- несколько независимых вариантов плана от разных моделей;
- проверка языка проекта;
- повторная попытка после пустого ответа модели;
- сохранение старых вариантов для сравнения.

### Техническая основа

- версия: `v0.5.0-alpha.1`;
- Git commit внутреннего репозитория: `ab97a8b`;
- платформа: Windows x64;
- формат: папочная сборка PyInstaller.

### Статус

Ранняя альфа-версия для ручного тестирования. Ошибки и незавершённые функции ожидаемы.
