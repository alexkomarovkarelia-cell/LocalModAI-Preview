# История выпусков

## v0.5.0-alpha.5 — Workspace, File Preview & Reliability Preview

В этой версии я продолжил развивать рабочее пространство проекта, реальные действия модели с файлами и надёжность фоновой памяти.

### Рабочие файлы и просмотр

Я добавил и улучшил:

- открытие текстовых файлов прямо в LocalModAI;
- встроенное редактирование и сохранение текста;
- открытие изображений;
- просмотр GIF;
- отдельное окно предпросмотра;
- добавление новых файлов в рабочее пространство;
- небольшие иконки, чтобы вкладки чатов и файлов легче различались.

### Первые реальные действия модели с файлами

В alpha.5 модель получила первый безопасный набор Workspace-действий:

- создание текстового файла;
- запись явно заданного текста;
- чтение существующего текстового файла;
- обязательное повторное чтение после создания, если это требуется задачей.

Пока я намеренно ограничил AI-файловые действия текстовыми файлами. Создание папок, сложное AI-редактирование, массовые операции и неточный поиск файлов оставлены на следующие этапы.

### Workspace Trust

Я добавил отдельный слой проверки реального выполнения.

Если модель просто пишет «готово», но подтверждённого Workspace-действия не было, LocalModAI не принимает такой ответ как выполненную задачу.

Если модель пропустила обязательный шаг, выбрала неправильное действие или преждевременно заявила об успехе, программа может дать ей ещё одну попытку выполнить нужное действие.

Из-за этого некоторые локальные модели иногда отвечают дольше, чем раньше: один пользовательский запрос может включать несколько внутренних попыток. Это сделано намеренно, чтобы снизить вероятность ложного «готово».

Финальное содержимое после чтения файла берётся из реального результата Workspace, а не из пересказа модели.

### Session Summary / background worker

Я продолжил исправлять технический контур фоновых итогов:

- усилено создание и восстановление BASE;
- улучшено согласование cursor / chunk / summary;
- добавлена защита от повторной генерации одного и того же диапазона после сбоя;
- улучшено восстановление фоновых задач после restart / crash;
- усилено определение устаревшей фоновой работы;
- неподтверждённые и технические сообщения лучше исключаются из долговременного Summary;
- запуск следующих итогов теперь лучше опирается на смысловой объём истории, а не на технический шум;
- улучшена диагностика background worker и причин recovery.

### Диагностика скорости

Я добавил дополнительный BrainPerf-контур, чтобы во время разработки видеть:

- сколько времени работала модель;
- сколько было обращений к модели;
- сколько было Workspace-действий;
- сколько времени заняли сами файловые операции.

Практические проверки показали, что Workspace-операции обычно занимают миллисекунды, а основная задержка приходится на генерацию модели и возможные повторные попытки.

### Проверка

Перед публикацией alpha.5:

- `3789 passed` в полном Windows-наборе автоматических тестов;
- Workspace create/read проверен на 8 локальных профилях разных семейств и на внешнем API;
- отдельно проверено чтение файла после ручного изменения пользователем;
- semantic trigger фоновых итогов проверен на реальном проекте с 12 чатами;
- portable ZIP собран из чистого Git-состояния;
- portable-сборка успешно запускается после чистой распаковки;
- встроенный `llama.cpp Runtime Pack` запускает локальную модель;
- создание и повторное чтение текстового файла через Workspace проверено уже в portable-сборке.

## v0.5.0-alpha.4 — Background Work, Recovery & Diagnostics Preview

Крупный публичный alpha-срез после цикла работ над фоновой Session Memory, восстановлением, ошибками и диагностикой.

### Главное

- фоновые BASE / CHECKPOINT итоги длинных сессий;
- durable background tasks;
- восстановление после части ошибок модели / runtime / API;
- Manual Retry;
- Attention Center для фоновых проблем;
- развитие общего Error Protocol;
- журнал ошибок и диагностики;
- настройки фоновых итогов в Диспетчере мозга;
- отдельное разрешение API для background Summary;
- настройка timeout;
- светофор реального состояния мозга и фоновой работы;
- улучшенная защита cursor / chunk / summary;
- bounded recovery вместо бесконечных повторов;
- Split/Merge, Compact Repair, Generation Headroom, Reasoning Headroom, Adaptive Baseline;
- release hygiene: runtime logs и prompt dumps не входят в публичную сборку.

### Проверка

- 3280 автоматических тестов — PASS;
- один 70K сценарий / 116 сообщений полностью обработан 8 локальными профилями и 1 API-профилем;
- во всех прогонах достигнуто 116/116 и `pending=False`;
- portable ZIP проверен на чистой распаковке;
- встроенный llama.cpp Runtime Pack работает;
- публичный ZIP не содержит исходники, тесты, `.venv`, guard logs, prompt dumps и GGUF-модели.

### Release candidate

- внутренний Git commit: `261e5c18c6f17e300ca5d21abe495879891c39d5`;
- Windows x64;
- portable ZIP;
- SHA256: `47A46DC678088D7FC3D37AAEA3EEA032972A1A035B15AA23D4E98DCDAD9EE078`.

### Важно

Summary Quality ещё не финальна. См. `KNOWN_ISSUES.md`.
