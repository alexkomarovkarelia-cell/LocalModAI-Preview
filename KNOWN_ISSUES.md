# Известные ограничения v0.5.0-alpha.1

Это ранняя тестовая версия.

- Локальная модель может неверно понять запрос пользователя.
- Модель может создать слишком общий или неполный план.
- Неподтверждённая идея модели иногда может попасть в краткое понимание проекта. Перед подтверждением обязательно проверяйте поля.
- Разные GGUF-модели дают сильно отличающиеся результаты.
- Некоторые модели могут отвечать медленно или завершать запрос без текста.
- Большие чаты пока могут обрезаться по лимиту контекста.
- Модель не входит в архив программы и подключается отдельно.
- Цифровой подписи Windows пока нет.
- Автоматического обновления пока нет.
- Программа пока не предназначена для хранения паролей, платёжных данных и критически важной информации.
- Интерфейс и формат хранения данных могут измениться в следующих сборках.

При обнаружении новой ошибки создайте Issue на GitHub.
