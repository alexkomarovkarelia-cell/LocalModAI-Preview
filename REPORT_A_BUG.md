# Как сообщить об ошибке

Откройте вкладку **Issues** в репозитории и выберите шаблон сообщения об ошибке.

## Сначала выберите тип

### TECH BUG

Техническая проблема программы, например:

- зависла фоновая задача;
- `pending` не снимается;
- пропал BASE / CHECKPOINT;
- Retry не запускает работу;
- после restart задача потерялась;
- runtime / API disconnect не восстановился;
- программа упала;
- светофор показывает неправильное состояние.

### SUMMARY QUALITY

Технически задача завершилась, но итог неверно понял смысл:

- предложение стало решением;
- перепутан автор утверждения;
- открытый вопрос стал отказом;
- придуманы факты;
- потерян важный результат;
- искажено состояние проекта.

## Укажите

1. Версию LocalModAI.
2. Версию Windows.
3. Тип: `TECH BUG` или `SUMMARY QUALITY`.
4. Что вы делали.
5. Что ожидали увидеть.
6. Что произошло на самом деле.
7. Повторяется ли проблема после перезапуска.
8. Название модели.
9. Размер / quantization GGUF.
10. Context window, если известен.
11. CPU.
12. GPU.
13. RAM.
14. Local / API.
15. Для background: BASE или CHECKPOINT.
16. Был ли Manual Retry и помог ли он.
17. Скриншот.

## Диагностические файлы

Перед прикреплением:

- откройте архив;
- проверьте текстовые и JSON-файлы;
- удалите личные данные;
- не публикуйте содержимое приватных проектов;
- не публикуйте пароли и API-ключи.

Если проблема относится к большой модели, особенно полезно указать:

- точное имя GGUF;
- quantization;
- время выполнения;
- где остановилась задача;
- сколько раз сработал recovery.
