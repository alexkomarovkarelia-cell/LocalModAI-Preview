# LocalModAI — Preview-сборки

LocalModAI — локальная модульная ИИ-платформа в активной разработке.

Сейчас проект находится на стадии **MVP 0.5 Preview**. Это ранняя тестовая версия для Windows, а не готовый продукт.

## Что можно проверить в v0.5.0-alpha.5

В этой версии я продолжил развивать рабочее пространство проекта, фоновые итоги и надёжность действий модели.

### Рабочие файлы и просмотр

Теперь можно:

- открывать текстовые файлы прямо в LocalModAI;
- редактировать и сохранять текстовые файлы во встроенном редакторе;
- открывать изображения;
- просматривать GIF;
- использовать отдельное окно предпросмотра;
- добавлять новые файлы в рабочее пространство;
- быстрее различать вкладки чатов и открытых файлов по небольшим иконкам.

### Первые реальные действия модели с файлами

В alpha.5 модель может выполнять первые реальные действия через Workspace / Рабочие файлы.

Пока я намеренно ограничил этот сценарий безопасным минимумом:

- модель может создать **текстовый файл**;
- записать в него явно заданный текст;
- прочитать существующий текстовый файл;
- после создания снова прочитать файл и подтвердить его фактическое содержимое.

Создание папок, сложное AI-редактирование файлов, массовые файловые операции и приблизительный поиск файлов пока не входят в этот prerelease.

### Проверка реального выполнения

Я добавил отдельный защитный слой, чтобы модель не могла просто написать «файл создан» или «файл прочитан», если фактически нужного Workspace-действия не было.

Если модель преждевременно сообщает об успехе или пропускает обязательный шаг, LocalModAI может отклонить такой результат и дать модели ещё одну попытку выполнить нужное действие.

Поэтому некоторые локальные модели теперь иногда отвечают дольше: один пользовательский запрос может включать несколько внутренних попыток. Это сделано намеренно, чтобы снизить вероятность ложного «готово».

Финальное содержимое после чтения файла берётся из реального результата Workspace, а не из пересказа модели.

### Session Summary / фоновые итоги

Я также продолжил исправлять и усиливать технический контур фоновых итогов:

- создание и восстановление BASE;
- согласование cursor / chunk / summary;
- защита от повторной генерации одного и того же диапазона после сбоя;
- восстановление фоновой задачи после restart / crash;
- определение устаревших фоновых задач;
- исключение неподтверждённых и технических сообщений из долговременного Summary;
- смысловой подсчёт объёма истории для запуска следующих итогов;
- улучшенная диагностика фонового worker и причин recovery.

### Диагностика скорости

Я добавил дополнительную диагностику выполнения запросов. Во время разработки теперь можно видеть:

- сколько времени работала модель;
- сколько было обращений к модели;
- сколько было Workspace-действий;
- сколько времени заняли сами файловые операции.

Практические проверки показывают, что сами Workspace-операции обычно занимают миллисекунды, а основное время приходится на генерацию модели и возможные повторные попытки.

## Проверка alpha.5

Перед публикацией:

- `3789 passed` в полном Windows-наборе автоматических тестов;
- Workspace create/read проверен на 8 локальных профилях разных семейств и на внешнем API;
- отдельно проверено чтение файла после ручного изменения пользователем;
- Summary semantic trigger проверен на реальном проекте с 12 чатами;
- portable ZIP собран из чистого Git-состояния;
- portable-сборка запускается после распаковки;
- встроенный `llama.cpp Runtime Pack` запускает локальную модель;
- создание и повторное чтение текстового файла через Workspace проверено уже в portable-сборке.

## Что ещё можно проверить

Нам особенно полезны результаты на железе и моделях, которых нет у разработчика:

- 14B / 24B / 27B / 32B+ GGUF;
- NVIDIA / AMD / CPU-only;
- 32 / 64 GB RAM;
- разные quantization;
- reasoning-модели;
- модели с большим context window;
- другие API / OpenRouter модели.

## Важно

Это alpha-версия.

Работа с файлами специально развивается небольшими безопасными шагами. Сейчас моделью поддерживаются прежде всего надёжное создание и чтение **текстовых файлов**.

Техническая надёжность фоновых итогов улучшена, но **смысловая точность Summary ещё не финальная**. Важные решения и факты всё ещё нужно проверять по исходному чату.

## Как установить

1. Откройте раздел **Releases**.
2. Скачайте `LocalModAI-v0.5.0-alpha.5-windows-x64.zip`.
3. Полностью распакуйте ZIP в отдельную папку.
4. Запустите `LocalModAI_MVP.exe`.
5. Добавьте совместимую GGUF-модель через папку `Models` / Диспетчер мозга.

Не запускайте приложение прямо из ZIP.

Windows SmartScreen или антивирус могут показать предупреждение: тестовая сборка пока не подписана цифровой подписью.

## Как сообщить об ошибке

Для технической ошибки помечайте отчёт как **TECH BUG**.

Для неверного смысла итогов помечайте как **SUMMARY QUALITY**.

Если ошибка связана с Workspace, полезно указать:

- какую модель вы использовали;
- что именно просили сделать с файлом;
- появился ли файл физически;
- сколько времени выполнялась задача;
- какой итоговый ответ показала модель.

Перед отправкой диагностических файлов проверьте, что в них нет личных данных, текста приватных проектов и API-ключей.
