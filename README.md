# LocalModAI — Preview-сборки

LocalModAI — локальная модульная ИИ-платформа, которую я постепенно создаю с нуля.

Сейчас проект находится на стадии **MVP 0.5 Preview**. Это ранняя тестовая версия для Windows, а не готовый продукт.

## Что можно проверить

- создание и открытие проектов;
- несколько связанных чатов внутри проекта;
- сохранение проектного контекста;
- подключение локальных моделей в формате GGUF;
- общение с локальной моделью;
- краткое понимание проекта;
- сбор контекста перед планированием;
- создание черновика плана;
- несколько вариантов плана от разных моделей.

## Важно

Программа активно разрабатывается. Возможны ошибки, зависания, неполные планы и неверное понимание текста моделью.

Не используйте эту версию для хранения паролей, платёжных данных и другой критически важной информации.

LocalModAI не включает ИИ-модель в архив. Пользователь подключает совместимую локальную GGUF-модель самостоятельно через менеджер моделей.

## Как установить

1. Откройте раздел **Releases** справа на странице репозитория.
2. Скачайте архив последней версии для Windows.
3. Полностью распакуйте ZIP-архив в отдельную папку.
4. Запустите `LocalModAI_MVP.exe`.
5. Через менеджер моделей укажите папку с вашей GGUF-моделью.

Не запускайте программу прямо из ZIP-архива.

Windows или антивирус могут показать предупреждение для неизвестного приложения. У первой тестовой сборки пока нет цифровой подписи.
